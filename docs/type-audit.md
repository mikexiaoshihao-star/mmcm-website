# Type audit

Latin text uses **JetBrains Mono**. Chinese characters use **MiSans Light** (the logo lockup and any glyph JetBrains Mono does not cover). Sizes, weights, and spacing below are the computed values on 2026-10-28 at 1440×900. They are a record, not a proposed scale.

The specified stacks are `"JetBrains Mono", ui-monospace, monospace` for Latin, and `"JetBrains Mono", "MiSans", sans-serif` where a string may contain Chinese. The logo lockup is `"MiSans", "Noto Sans SC", sans-serif` so the six Chinese characters stay in MiSans, with the small local Noto subset only if MiSans has not loaded.

There was no site 404. `src/404.njk` now publishes `/404.html` in JetBrains Mono for the host's missing-page response.
